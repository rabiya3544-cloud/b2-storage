Video Upload & Download

POST/api/upload-from-url›

Server fetches a remote video from an allow-listed TikTok CDN host, streams it into B2, uploads an optional cover, and inserts a b2_files row. Failures are logged to failed_uploads.

🔒 X-API-Key Body (JSON)
FieldType
urlstringrequired
coverImgstringoptional
userIdstringoptional (default user_123)
datestringoptional
likesintegeroptional
cURL 
curl -X POST $BASE/api/upload-from-url \
  -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"url":"https://…tiktok…/v.mp4","userId":"u1","likes":42}'
Response (200) 
{ "success": true, "videoKey": "video_….mp4",
  "coverKey": "cover_….jpg", "bytes": 12345678 }
Max file size 300 MB · upstream timeout 90 s · only allow-listed TikTok hosts.

Cover Upload → Vercel Blob

POST/api/upload-cover-to-blob›

Two modes on the same URL:

  • multipart/form-data — browser sends bytes directly (preferred)
  • application/json — server fetches the image from an allow-listed TikTok CDN
🔒 X-API-Key Multipart fields
filerequired image, ≤10 MB
date,likes,userId,sourceLinkoptional
JSON fields
coverImgrequired URL
date,likes,userId,sourceLinkoptional
Response 
{ "success": true,
  "pathname": "u1/cover_2025-01-01.jpg",
  "url": "https://…public…",
  "contentType": "image/jpeg",
  "size": 45678 }
Blob path: {userId}/cover_{date}.{ext}. CORS-friendly, no auth needed to read url.
